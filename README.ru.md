# tokyo-night-by-machineslego-wq Theme для Obsidian

[English](./README.md) | **Русский**

Строгая, плоская и яркая тема для Obsidian, вдохновлённая цветовой палитрой **Tokyo Night**.

Эта тема — логическое продолжение настройки моего рабочего окружения. Если вы хотите, чтобы ваши заметки выглядели так же строго, как терминал, оконный менеджер и панель, эта тема для вас.

## ✨ Особенности

- **Плоский дизайн:** Никаких отвлекающих теней и лишних скруглений. Строго, чисто и минималистично.
- **Яркие акценты:** Отлично читаемое выделение маркером (`==`), выразительная типографика для жирного, курсива и жирного курсива.
- **Умные Callouts:** Полностью стилизованы и адаптированы под ПК и смартфоны. Поддерживаются кастомные теги.
- **Edit = Read:** Режим редактирования (Live Preview) настроен так, чтобы выглядеть почти неотличимо от режима чтения.
- **Два режима:** Полная поддержка как тёмной, так и светлой (Day) темы Obsidian.
- **Поддержка Style Settings:** Каждый цвет в теме можно изменить через GUI — без правки CSS. Отдельные пикеры для тёмной и светлой темы.

## 📦 Установка

### Способ 1: Ручная установка (Linux и Windows)

Это самый надёжный метод, если вы хотите установить тему напрямую из исходников.

**Linux:**
1. Скачайте файлы `theme.css` и `manifest.json` из этого репозитория.
2. Откройте терминал и перейдите в папку тем вашего хранилища Obsidian:
   ```bash
   cd /путь/к/вашему/хранилищу/.obsidian/themes/
   ```
   *Если папки `themes` нет, создайте её: `mkdir -p .obsidian/themes/`*
3. Создайте папку для темы (например, `tokyo-night-by-machineslego-wq`) и скопируйте туда файлы:
   ```bash
   mkdir "tokyo-night-by-machineslego-wq"
   cp ~/Downloads/theme.css ~/Downloads/manifest.json "tokyo-night-by-machineslego-wq/"
   ```
4. Перезапустите Obsidian, зайдите в **Настройки → Внешний вид → Темы** и выберите **tokyo-night-by-machineslego-wq**.

**Windows:**
1. Скачайте файлы `theme.css` и `manifest.json`.
2. Откройте проводник и перейдите в папку вашего хранилища.
3. Зайдите в папку `.obsidian`, затем в `themes`. (Если папки `themes` нет, создайте её).
4. Создайте новую папку с названием `tokyo-night-by-machineslego-wq` и положите в неё оба файла.
5. Перезапустите Obsidian, зайдите в **Настройки → Внешний вид → Темы** и выберите **tokyo-night-by-machineslego-wq**.

### Способ 2: Через BRAT (Автообновление с GitHub)

[BRAT](https://github.com/TfTHacker/obsidian42-brat) (Beta Reviewers Auto-update Tester) — это плагин, который позволяет устанавливать и автоматически обновлять темы напрямую из репозитория GitHub.

1. Установите и включите плагин **BRAT** в разделе **Настройки → Сторонние плагины**.
2. Откройте **Настройки → BRAT → Beta Themes List**.
3. Нажмите **Add Beta Theme** и введите URL репозитория:
   ```
   https://github.com/machineslego-wq/tokyo-night-by-machineslego-wq
   ```
4. Тема установится. Зайдите в **Настройки → Внешний вид → Темы** и выберите **tokyo-night-by-machineslego-wq**.

### Способ 3: Из релизов GitHub (ZIP)

Если вы предпочитаете скачивать готовый архив:

1. Перейдите на страницу [Releases](https://github.com/machineslego-wq/tokyo-night-by-machineslego-wq/releases).
2. Скачайте последний `.zip` файл (например, `tokyo-night-by-machineslego-wq-X.X.X.zip` — точное имя смотрите в последнем релизе).
3. Распакуйте архив в папку `.obsidian/themes/` вашего хранилища.
   *Убедитесь, что итоговый путь выглядит так: `<хранилище>/.obsidian/themes/tokyo-night-by-machineslego-wq/`*
4. Перезапустите Obsidian, зайдите в **Настройки → Внешний вид → Темы** и выберите **tokyo-night-by-machineslego-wq**.

## 🎨 Кастомизация

### Через Style Settings (рекомендуется)

Тема полностью поддерживает **[Style Settings](https://github.com/mgmeyers/obsidian-style-settings)**. Каждый цвет можно изменить через графический интерфейс — без правки CSS.

1. Установите и включите плагин **Style Settings** в разделе **Настройки → Сторонние плагины**.
2. Откройте **Настройки → Style Settings → Tokyo Night Theme**.
3. Меняйте любой цвет — **отдельные пикеры для тёмной и светлой темы**.

Доступные настройки:

- **Фоны** — основной, альтернативный, вторичный, границы
- **Текст** — обычный, приглушённый, едва заметный, на акценте
- **Акценты** — основной акцент и hover (влияет также на каретку и интерактивные элементы)
- **Заголовки** — H1–H6
- **Инлайн-форматирование** — жирный, курсив, жирный курсив
- **Выделение** — фон и цвет текста `==выделенного==`
- **Цитаты** — цвет акцента для рамки и полупрозрачного фона
- **Блоки кода** — 12 цветов (комментарий, функция, ключевое слово, оператор, свойство, пунктуация, строка, тег, значение, важное, обычный, фон)
- **Теги** — фон и цвет текста `#тегов`
- **Callouts** — 5 семантических цветов (синий / зелёный / жёлтый / красный / фиолетовый)
- **PDF-теги** — фон и цвет текста метки PDF-файлов

Изменения применяются мгновенно. Все значения по умолчанию совпадают с оригинальной палитрой Tokyo Night.

### Ручной CSS

Если не хотите использовать Style Settings — можно править `theme.css` напрямую. В начале файла переменные `body.theme-dark` / `body.theme-light`, любое изменение — одна строка.

## 🔄 Обновление

- **Ручная установка:** Скачайте последние `theme.css` и `manifest.json` из репозитория и замените существующие файлы в папке `.obsidian/themes/tokyo-night-by-machineslego-wq/`. Перезапустите Obsidian или используйте палитру команд (`Ctrl+P`) → **Reload app without saving**.
- **BRAT:** BRAT проверяет обновления автоматически. Вы также можете запустить проверку вручную в **Настройки → BRAT**.
- **Релизы GitHub:** Скачайте новый `.zip` со страницы релизов и распакуйте его поверх существующей папки, заменив старые файлы.
